# Lean Vibes

Official web platform for **Lean Vibes**, a music record label and creative collective. Built for speed, bold editorial typography, and fluid motion using the Next.js App Router and Tailwind CSS v4.

## Features

- **Editorial Dark UI**: High-contrast dark theme (`#121212` ink) paired with Sora typography and a swappable brand accent token (`#E50914`).
- **Fluid Motion**: Custom Framer Motion transitions, preloader sequence, smooth scrolling, and infinite marquee animations with `prefers-reduced-motion` support.
- **Responsive Architecture**: Fluid `clamp()` display typography and adaptive layouts across mobile, tablet, and ultra-wide screens (`max-w-[1440px]`).
- **Core Pages**: Landing page, About, Services, Contact, and Legal pages, structured to scale for an upcoming Merch/Shop section.

## Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Language**: [TypeScript 5](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) (CSS-first `@theme` configuration)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: [Sora](https://fonts.google.com/specimen/Sora)
